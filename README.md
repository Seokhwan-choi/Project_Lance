# 모바일 방치형 RPG - 랜스키우기

Unity로 개발한 2D 방치형 RPG 게임입니다. 자동 전투, 성장, 장비 강화/재련, 신수(펫), 던전 등 다양한 RPG 요소를 구현하였으며, UI/UX 흐름과 데이터 흐름까지 모두 직접 설계 및 개발하였습니다.

---

## 🎮 게임 개요

- **장르**: 2D 방치형 RPG
- **플랫폼**: Android (모바일)
- **그래픽**: 도트 기반 SD 캐릭터 스타일
- **개발 인원**: 2인 (기획/개발 전반 담당)

---

## 🧩 주요 구현 기능

| 시스템 | 설명 |
|--------|------|
| ⚔ 전투 시스템 | ActionManager를 통한 자동 전투 루프 구현<br>공격 범위 내 적 감지 후 이동 중지 → 공격 수행<br>DamageInst를 통해 상태/장비/스킬을 반영한 데미지 계산 |
| 📈 성장 시스템 | 경험치 누적 → 자동 레벨업, 능력치 상승 구조<br>성장 곡선을 직접 설계하여 밸런싱 조정<br>골드 훈련, 한계 돌파, 유물 강화 등|
| 🧤 장비 시스템 | 무기/방어구/장신구 착용 슬롯 구현<br>강화석을 사용한 장비 강화 로직 및 단계별 능력치 상승<br>일정 확률에 따라 장비 최고 레벨을 상승시켜주는 재련 시스템<br>같은 등급의 장비를 합성하여 다음 등급의 장비 획득 |
| 🐾 신수 시스템 | 속성별 신수 구현 <br>속성에 따른 데미지 계산<br>신수 강화 및 진화 시스템<br>신수 전용 스킬 및 특성 |
| 🏰 던전/스테이지 | 일반 스테이지 및 특수 던전 구조<br>난이도 기반 보상/출현 몬스터 조정 |
| 🖥️ UI 시스템 | 체력 게이지 UI, DoTween 애니메이션, 탭/팝업 UI 설계 |
